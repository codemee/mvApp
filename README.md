# mvApp

把視窗從一個螢幕「拖放」到另一個螢幕的 Windows 小工具。

打開主視窗後，每個螢幕會有一個窗格，窗格裡用應用程式圖示列出目前在該螢幕上的視窗。把圖示拖到另一個螢幕的窗格再放開，視窗就會搬過去。

## 下載與使用
1. 到 [Releases](../../releases) 頁面下載 `mvapp.exe`（單一檔案、免安裝、Windows x64）。
2. 雙按執行。啟動後只會出現在系統匣（工作列右下角），**雙按系統匣圖示**開啟主視窗。
3. 想讓它隨 Windows 啟動：在系統匣圖示按右鍵，勾選「開機自動執行」。

> 此執行檔沒有程式碼簽章，Windows SmartScreen 第一次執行時可能顯示警告，選「其他資訊」→「仍要執行」即可。

## 怎麼用
- **搬移視窗**：把圖示拖到另一個螢幕的窗格放開。視窗會保持原本的相對位置與大小；最大化的視窗搬過去後仍是最大化，最小化的仍是最小化。
- **切換到某個視窗**：點一下它的圖示。
- **工具列**：
  - 左邊是「重新整理」。
  - 右邊有兩個按鈕，**點一下就切換到下一個狀態**，滑鼠停在上面會顯示目前狀態：
    - 配色：隨系統（半實心圓）→ 淺色（太陽）→ 深色（月亮）。
    - 語言：隨系統（地球）→ 繁體中文（中）→ English（En）。
- **系統匣**：關閉視窗不會結束程式，只是縮回系統匣。要真正結束，請在系統匣圖示按右鍵選「結束」。

## 特色
- 每個螢幕一個窗格，依實體位置由左到右排列，並標示解析度與主要螢幕。
- 視窗太窄時，窗格會自動改成上下排列。
- 自動更新視窗清單，接上或拔除螢幕也會跟著變化。
- 只會執行一份：已經在執行時再啟動一次，只會把原本的主視窗叫出來。
- 淺色配色取自鋼彈 RX-78-2，深色配色取自新世紀福音戰士初號機。

## 常見問題
**啟動後沒有看到視窗？**
這是正常的，程式一開始只放在系統匣。雙按系統匣圖示即可開啟；如果沒看到圖示，請點系統匣的「顯示隱藏的圖示」箭頭。

**有些視窗搬不動？**
以系統管理員身分執行的程式，必須讓 mvApp 也以系統管理員身分執行才能搬動它。

**想把設定還原成預設？**
設定（配色、語言）會自動記住。結束程式後刪除 `%APPDATA%\mvapp\settings.txt` 即可還原。

## 限制
- 僅支援 Windows（在 Windows 11 上開發與測試）。
- 不支援在多個虛擬桌面之間搬移視窗。
