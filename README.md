# mvApp

Windows 專用的多螢幕視窗搬移工具（Rust + egui）。

依目前使用中的螢幕分成窗格，窗格內以應用程式圖示列出該螢幕上的 GUI 視窗；把圖示拖放到另一個螢幕的窗格，即可把視窗搬過去。

## 功能
- 每個螢幕一個窗格（依實體左右排列），標題前有螢幕圖示，標示解析度與主要螢幕。
- 視窗過窄時，窗格自動改成上下排列。
- 列出可見的頂層視窗（排除工具視窗、被 cloak 的視窗、桌面與本程式自身）。
- 拖放搬移：保持相對位置與大小；最大化視窗搬移後重新最大化；最小化視窗搬移後維持最小化。
- 點擊圖示可把該視窗帶到前景。
- 自動刷新，支援螢幕熱插拔。
- 系統匣常駐：啟動時只顯示在系統匣；雙按系統匣圖示開啟主視窗；按關閉鈕會縮回系統匣。系統匣右鍵選單有「開機自動執行」（勾選切換，寫入目前使用者的 HKCU\...\Run，不需系統管理員權限）與「結束」（才會真正結束程式）。
- 只會執行一份：已有實例在執行時，再次啟動只會把既有的主視窗叫出來，新的程序隨即結束（同一個 Windows 登入工作階段內有效）。
- 工具列左側是重新整理，右側是兩個扁平的三態單鍵，點一下切換到下一個狀態：配色（隨系統〔半實心圓〕→淺色〔太陽〕→深色〔月亮〕）與語言（隨系統〔地球〕→繁體中文〔中〕→English〔En〕），設定會儲存於 `%APPDATA%\mvapp\settings.txt`。
- Windows 11 Fluent 式的輕量風格：中性底色、細框群組（標題嵌在框線上）、內部白色清單區、灰色細線條圖示。淺色配色的強調色取自鋼彈 RX-78-2（藍、紅、黃），深色配色取自新世紀福音戰士初號機（暗紫、螢光綠、橘），用於螢幕圖示與拖放高亮。

## 下載與使用
1. 到 [Releases](../../releases) 頁面下載 `mvapp.exe`（單一檔案、免安裝、Windows x64）。
2. 雙按執行。啟動後只會出現在系統匣，雙按系統匣圖示開啟主視窗。
3. 想讓它隨 Windows 啟動：在系統匣圖示按右鍵，勾選「開機自動執行」。

> 此執行檔沒有程式碼簽章，Windows SmartScreen 第一次執行時可能顯示警告，選「其他資訊」→「仍要執行」即可。

## 建置與執行
```powershell
cargo run --release
cargo test
```

## 限制
- 以系統管理員身分執行的視窗，需以系統管理員身分啟動 mvapp 才能搬移（UIPI）。
- 目前不支援多個虛擬桌面的視窗切換。
